# Правила работы

- Работай только в этой папке. Перед изменениями прочитай текущие файлы.
- Делай только ту функцию, которую просит пользователь. Сохраняй уже работающие функции.
- Используй только обычные HTML, CSS и JavaScript: без npm, фреймворков и внешних ресурсов.
- Храни данные пользователя в браузере. Ничего не отправляй в интернет.
- Делай понятные подписи. Поля и кнопки должны быть высотой не меньше 44 px. Обеспечь работу с клавиатуры и на телефоне.
- Показывай денежные суммы с пробелами между тысячами, например `15 000 ₸`. Пустые и неверные числа считай нулём; никогда не показывай `NaN`.
- Не запускай git и ничего не публикуй без просьбы пользователя.
- После работы перечисляй изменённые файлы и объясняй, как проверить результат.
