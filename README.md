# Коммерческое предложение HSE Company

Простое веб-приложение для подготовки коммерческого предложения с расчётом стоимости услуг и сохранением в PDF.

## Файлы приложения

- `index.html` — структура страницы: подписи, поля, кнопки и область коммерческого предложения.
- `styles.css` — внешний вид и удобная раскладка для компьютера и телефона.
- `script.js` — расчёты, работа с данными и подготовка документа к сохранению в PDF.

## Как открыть

Дважды щёлкните по файлу `index.html`: приложение откроется в браузере. Установка и запуск сервера не нужны.

## Как проверить

Добавьте две позиции: количество **2** по цене **15 000 ₸** и количество **1** по цене **8 000 ₸**. Итог должен составить **38 000 ₸**.

Для проверки PDF заполните номер, дату и комментарий. Нажмите **«Сохранить PDF»** и в окне печати выберите **«Сохранить как PDF»**. В предпросмотре должны быть заголовок коммерческого предложения, таблица с рамками, итоги справа и комментарий. Кнопки и поля настройки расчёта на печати скрыты; суммы совпадают с экраном.

Черновик сохраняется в браузере после каждого изменения. Заполните коммерческое предложение и обновите страницу клавишей **F5**: данные должны остаться. Кнопка **«Новое коммерческое предложение»** после подтверждения очищает черновик и увеличивает номер. Кнопка **«Скопировать для WhatsApp»** копирует готовый текст; вставьте его в заметки для проверки. Если браузер запретит копирование, текст появится в поле для ручного копирования.

В верхней части страницы показан логотип HSE Company. Под таблицей указано, что HSE Company является плательщиком НДС, а ниже оставлено поле для свободного комментария.

В таблице указаны услуга, количество и цена в тенге. Общая сумма остаётся в итоговом расчёте под таблицей. Названия введённых услуг сохраняются в браузере отдельно от текущего черновика: начните вводить первые буквы в поле «Наименование» и выберите подходящую услугу из подсказок. Кнопка «Новое коммерческое предложение» очищает черновик, но сохраняет список услуг.
