# Смета за 5 минут

Простое веб-приложение, в котором можно быстро составить смету или коммерческое предложение и сохранить его в PDF. Оно предназначено для предпринимателей, готовящих КП клиентам, и офисных сотрудников, составляющих сметы закупок и расчёты расходов для руководителя.

## Файлы приложения

- `index.html` — структура страницы: подписи, поля, кнопки и область сметы.
- `styles.css` — внешний вид и удобная раскладка для компьютера и телефона.
- `script.js` — расчёты, работа с данными и подготовка документа к сохранению в PDF.

## Как открыть

Дважды щёлкните по файлу `index.html`: приложение откроется в браузере. Установка и запуск сервера не нужны.

## Как проверить

Добавьте две позиции: количество **2** по цене **15 000 ₸** и количество **1** по цене **8 000 ₸**. Итог должен составить **38 000 ₸**.

Для проверки PDF заполните номер, дату, реквизиты и комментарий. Нажмите **«Сохранить PDF»** и в окне печати выберите **«Сохранить как PDF»**. В предпросмотре должны быть заголовок сметы, реквизиты, таблица с рамками, итоги справа, комментарий и строка подписи. Кнопки и поля настройки расчёта на печати скрыты; суммы совпадают с экраном.

Черновик сохраняется в браузере после каждого изменения. Заполните смету и обновите страницу клавишей **F5**: данные должны остаться. Кнопка **«Новая смета»** после подтверждения очищает черновик и увеличивает номер. Кнопка **«Скопировать для WhatsApp»** копирует готовый текст; вставьте его в заметки для проверки. Если браузер запретит копирование, текст появится в поле для ручного копирования.
